# Explaining red flags

Use `references/findings.md` to translate finding ids into plain-language explanations and advice.
Always explain *who really owns the link*: the part immediately before the domain ending (e.g. in
`paypal.com.account-verify.example` the owner is `account-verify.example`, not PayPal).

Tone: calm, specific, no jargon. One action per answer ("open the official app instead").
